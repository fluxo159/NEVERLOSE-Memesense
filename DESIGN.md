# 🎨 Единый Дизайн-Код Проекта: Linear Dark Design System
> Источник: [awesome-design-md / linear.app](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md)

Данный документ является **единственным обязательным стандартом интерфейса** для всех разработчиков и дизайнеров проекта. Все компоненты, цвета, отступы и типографика должны строго соответствовать этой спецификации.

---

## 1. 🌌 Базовая Цветовая Палитра (Surfaces & Canvas)

Интерфейс строится по 4-уровневой лестнице поверхностей (Surface Ladder) без использования ярких градиентов или разнородных фонов.

| Токен | HEX / Значение | CSS класс Tailwind | Назначение |
| :--- | :--- | :--- | :--- |
| **Canvas** | `#08090C` | `bg-canvas` | Основной глубокий фон страницы |
| **Surface 1** | `#0E1117` | `bg-surface-1` | Базовые карточки, панели, модальные окна, таблицы |
| **Surface 2** | `#151922` | `bg-surface-2` | Вложенные блоки, строки списков при наведении, инпуты |
| **Surface 3** | `#1E2330` | `bg-surface-3` | Активные переключатели, поднятые бейджи, кнопки |
| **Hairline (Border)** | `rgba(255, 255, 255, 0.08)` | `border-white/[0.08]` | Стандартные тонкие 1px границы карточек и разделителей |
| **Hairline Strong** | `rgba(255, 255, 255, 0.16)` | `border-white/[0.16]` | Границы при наведении (`hover:border-white/[0.16]`) |

## 2. ⚡ Акцентные и Семантические Цвета

В соответствии с философией Linear, акцентные цвета используются точечно и функционально:

| Роль | Цвет / Токен | Tailwind класс | Где применяется |
| :--- | :--- | :--- | :--- |
| **Primary Accent (Indigo/Lavender)** | `#6366F1` | `text-indigo-400`, `bg-indigo-600` | Главные кнопки, иконки навигации, активный фокус |
| **Успех / Занят (Success)** | `#10B981` | `text-emerald-400`, `bg-emerald-500/15` | Статус «Работает», успешные действия |
| **Внимание / Требует проверки (Urgent)** | `#F43F5E` | `text-rose-400`, `bg-rose-500/15` | Карточка дня, статус «Нужен визит» |
| **Обучение / Моноцентр (Education)** | `#06B6D4` | `text-cyan-400`, `bg-cyan-500/15` | Статус «Учится», курсы, профподготовка |
| **Бизнес / ИП (Business)** | `#8B5CF6` | `text-purple-400`, `bg-purple-500/15` | Предприниматели, субсидии, гранты |

## 3. ✍️ Типографика и Текст (Text & Contrast)

- **Основной шрифт:** `Inter`, `SF Pro Display`, `system-ui`.
- **Заголовки (`text-white`):** `font-bold` или `font-semibold` с легким отрицательным трекингом (`tracking-tight`).
- **Основной текст (`text-slate-300` / `text-slate-400`):** `text-xs` или `text-sm`, высокая читаемость на тёмном фоне.
- **Подписи и метаданные (`text-slate-500`):** `text-[10px]` или `text-[11px]`.
- **Моноширинный текст (`font-mono`):** `text-slate-400`, используется для дат, ID и статистики.

---

## 4. 🔲 Скругления и Радиусы (Border Radius)

| Размер | Значение | Tailwind класс | Использование |
| :--- | :--- | :--- | :--- |
| **sm / md** | `6px – 8px` | `rounded-lg` | Кнопки действий, инпуты, теги |
| **lg** | `12px` | `rounded-xl` | Карточки реестра, элементы списков |
| **xl / 2xl** | `16px – 20px` | `rounded-2xl` | Основные дашборд-панели, модальные окна |
| **pill** | `9999px` | `rounded-full` | Статус-бейджи, индикаторы пульса |

---

## 5. 🗺️ ГИС-Карта (Map Aesthetics)

- **Базовая подложка:** `CartoDB Dark Matter` (тёмный векторный стиль без визуального шума).
- **Махалли (Полигоны):** Прозрачный слой с тонкой обводкой цвета акцента (`#6366F1` / `#10B981` / `#F43F5E`) в зависимости от уровня занятости.
- **Инфраструктура (POI):** Контрастные круглые маркеры с иконками ключевых объектов (Моноцентры, IT-Парки, Центры занятости).

---

## 6. 🚫 Главные "НЕЛЬЗЯ" (Anti-Patterns)

1. ❌ **Никаких белых/светлых экранов:** весь интерфейс строго в тёмной теме Linear Dark.
2. ❌ **Никаких радужных градиентов на всю страницу:** градиенты допускаются только лёгкие 10% затемнения (`from-surface-1 via-surface-2 to-surface-1`).
3. ❌ **Никаких тяжелых размытых теней:** глубина задается уровнями `bg-surface-1` $\rightarrow$ `bg-surface-2` $\rightarrow$ `bg-surface-3` и границами `border-white/[0.08]`.
4. ❌ **Никаких неструктурированных цветов:** используйте только токены из таблицы выше.
