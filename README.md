# 🏛️ «Ёшлар Бандлиги» — Платформа мониторинга занятости и маршрутизации молодёжи

### Хакатон NEXUS30 — Трек GovTech (Кейс A)
**Пилотный полигон:** Мирзо-Улугбекский район г. Ташкента

---

## 📌 О проекте

Цифровая веб-платформа для хокимията района и лидеров махаллей («Ёшлар етакчиси»), обеспечивающая единый учёт молодёжи (18–30 лет), предиктивное выявление скрытой безработицы (NEET), верификацию статуса на месте и адресную маршрутизацию в государственные программы поддержки (Моноцентр «Ишга Мархамат», IT-Park, субсидии «Ёшлар Дафтари»).

---

## 🚀 Ключевой функционал

1. **Сводный ситуационный дашборд:**
   - Мониторинг ключевых KPI района и махаллей (занятые, студенты, безработные, NEET).
   - Интерактивная аналитика структуры занятости (Recharts).
   - Ролевой доступ: Хокимият / Лидер махалли / Центр занятости.

2. **NEET Триаж & Human-in-the-Loop:**
   - Алгоритмическое выявление кандидатов в категорию NEET.
   - Протокол личной верификации статуса уполномоченным сотрудником.

3. **Единый реестр и карточка молодёжи:**
   - Полнотекстовый поиск, расширенная фильтрация по полу, возрасту, статусу, махалле.
   - Хронологический таймлайн жизненного цикла статусов.
   - **Smart Routing Engine:** персональный подбор и назначение мер поддержки.

4. **Интерактивная ГИС-карта махаллей:**
   - Схема секторов Мирзо-Улугбекского района с цветовой тепловой индикацией плотности NEET.
   - Паспорта территорий с прямыми контактами лидеров молодёжи.

5. **Импорт и Экспорт:**
   - Выгрузка реестра в Excel (CSV с UTF-8 BOM) и структурированный JSON.
   - Импорт внешней таблицы CSV прямо в интерфейсе.

6. **Встроенный Питч-гид для защиты перед жюри:**
   - 3-минутный пошаговый сценарий демонстрации с полным покрытием всех 4 критериев оценки.

## 🛠 Стек технологий

- **Фронтенд:** React 18, TypeScript, Vite
- **Стилизация:** Tailwind CSS, Glassmorphism GovTech UI
- **Графика и иконки:** Recharts, Lucide React
- **Языки интерфейса:** Русский (RU) / Узбекский (O'Z)

## 💻 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка продакшн-версии
npm run build
```

Приложение будет доступно по адресу: `http://localhost:5173/`
